# Sources

This folder contains raw source materials — articles, papers, notes, transcripts, PDFs converted to markdown, etc.

**Rules:**
- Files here are **never modified** once added
- The LLM reads these but does not edit them
- One file per source
- Naming convention: `YYYY-MM-DD_author_title-slug.md` (or just descriptive slug)

Drop new sources here, then tell Claude: **"ingest [filename]"**

## Tips
- Use **Obsidian Web Clipper** to clip web articles directly as markdown
- For PDFs: export to markdown or paste key sections
- Images are fine — place in `sources/attachments/`
