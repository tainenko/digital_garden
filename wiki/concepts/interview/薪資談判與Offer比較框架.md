# 薪資談判與 Offer 比較框架

## 核心心態

> **談判是雙方都預期的流程，不是對抗。** 沒有公司因為應聘者要求更高薪水就撤回 Offer（除非態度惡劣）。

- 初始 Offer **幾乎永遠不是最終數字**，HR 有談判空間
- 沉默是談判工具：說完訴求後**閉嘴等待**
- 多個 Offer 是最強談判籌碼：創造競爭是合法策略
- 書面確認所有承諾，口頭承諾不算數

---

## 談判時機

```
技術面試通過 → HR 提出 Offer → [黃金談判窗口] → 簽約
```

**在以下情況下不要談判**：
- 面試過程中（「您的薪資期望是多少？」← 這是陷阱）
- 簽約之後
- 通過率極低的 Offer（需先評估自身槓桿）

**如何應對「薪資期望」提問**：
```
「我目前更想了解這個職位的完整範疇和發展潛力。
 能請您分享這個職位的薪資區間嗎？」

若被逼問，給範圍而非單點：
「根據我的研究和市場行情，我期望在 X 到 Y 之間，
 當然具體數字取決於整體補償套餐。」
```

---

## 薪資結構完整拆解

不要只看底薪，計算 **Total Compensation（TC）**：

```
TC = Base Salary
   + Annual Bonus（績效獎金，通常 10–30%）
   + Sign-on Bonus（入職獎金，多數一次性）
   + RSU/Stock（股票，通常 4 年 vesting）
   + 其他福利折現（保險、健身、WFH 補貼等）
```

### 股票（RSU）計算範例

```
RSU Grant: $100,000（4 年 vest，每年 25%）
第一年實際股票收入 = $100,000 × 25% = $25,000

若公司股價上漲 20%：
第一年實際收入 = $25,000 × 1.2 = $30,000

若公司為私有公司（Pre-IPO）：
股票流動性風險高，需大幅折現（通常打 3–7 折估值）
```

## 談判腳本

### 第一步：表達感謝 + 索取書面版本

```
「非常感謝您的 Offer！我很興奮有機會加入 [公司名]。
 能否請您發送書面版本，讓我可以仔細審閱所有細節？」
```

（爭取 5–7 個工作日的考慮時間是正常要求）

### 第二步：提出反要求（Counter Offer）

```
「感謝您提供詳細的 Offer。在仔細考慮後，
 我對這個機會非常感興趣，但在薪資方面，
 根據我的經驗、市場調研，以及我目前的其他機會，
 我希望底薪能調整到 [目標數字]。
 這對您來說可行嗎？」
```

**原則**：
- 只說一次具體數字，不要說「越多越好」
- 目標數字設在期望值上方 15–20%（留談判空間）
- 給出理由（市場行情、其他 Offer、技能稀缺性）

### 有競爭 Offer 時

```
「我目前還有另一家公司的 Offer，底薪是 [X]。
 我對 [你的公司] 更感興趣，但若能在薪資上更接近，
 我可以更快做決定。」
```

### 底薪無法動時：談其他項目

```
「我理解底薪的空間有限。那入職獎金方面是否有彈性？
 或者 RSU grant 能否調整？」

可談判的項目清單：
□ Sign-on Bonus（入職獎金）
□ RSU Grant（股票數量）
□ 年假天數
□ WFH 政策
□ 職位頭銜（影響未來 leveling）
□ 考核周期（提前到 6 個月而非 12 個月）
□ 辦公設備補貼
```

## Offer 比較框架

### 量化評分表

| 項目 | 權重 | 公司 A | 公司 B | 公司 C |
|------|------|-------|-------|-------|
| **TC（年薪+獎金+股票）** | 30% | 200萬 | 180萬 | 160萬 |
| **成長與學習** | 25% | 8/10 | 9/10 | 7/10 |
| **工作生活平衡** | 20% | 6/10 | 8/10 | 9/10 |
| **產品影響力** | 15% | 9/10 | 7/10 | 6/10 |
| **公司穩定性/前景** | 10% | 9/10 | 8/10 | 5/10 |
| **加權總分** | — | 7.65 | 8.15 | 7.25 |

### 非量化問題清單

```
問主管/HR：
□ 這個職位前任為何離開？
□ 團隊目前最大的技術挑戰是什麼？
□ 我的第一個 90 天的成功看起來像什麼？
□ 晉升的標準是什麼？上次有人在幾年內晉升？
□ 公司未來 1–2 年的技術路線圖是？

問潛在同事（非正式管道 LinkedIn 等）：
□ 你最享受在這裡工作的什麼？
□ 最大的挑戰或不滿是什麼？
□ 你會推薦朋友來這裡嗎？
```

## 台灣 vs 海外薪資市場差異

### 台灣市場現況（2025）

| 職級 | 台灣本土（年薪 TWD） | 台灣外商（年薪 TWD） |
|------|-------------------|-------------------|
| Junior（0–3年） | 60–90 萬 | 90–140 萬 |
| Mid（3–6年） | 90–150 萬 | 140–220 萬 |
| Senior（6–10年） | 150–250 萬 | 200–350 萬 |
| Staff/Principal（10年+） | 250–400 萬 | 350–600 萬 |

### 跳槽加薪合理期望

- **主動跳槽**：20–35% 增幅是常態，低於 15% 建議慎重
- **被動獵頭**：30–50% 增幅方值得考慮（轉換成本 + 適應風險）
- **轉外商**：底薪可能與本土相近，但股票/獎金差異大

## 談判後的結束語

接受 Offer：
```
「非常感謝您的善意回應。我很高興接受這份 Offer，
 期待與您和團隊一起工作！請告訴我下一步的流程。」
```

婉拒 Offer（保持關係）：
```
「感謝您整個過程的時間和努力。在深思熟慮後，
 我決定接受另一個機會，但這完全不反映我對 [公司] 的看法。
 若未來有合適的機會，希望我們還有機會合作。」
```

## 常見面試問題（被問到時）

**Q: 現在的薪水是多少？**
A（部分地區法律禁止問）：「我更希望聚焦在這個職位的市場行情，而不是我目前的薪水。」

**Q: 您有多少時間做決定？**
A：「大概需要一週時間完整評估，這對您來說可以嗎？」（不要說「我要考慮其他 Offer」，說「我需要完整評估」）
