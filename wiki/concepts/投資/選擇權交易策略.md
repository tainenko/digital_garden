# 選擇權交易策略

選擇權（Options）核心策略速查，聚焦 [[Claude Code量化交易四層系統]] 中用到的實戰策略。

---

## 基礎概念

### Implied Volatility（IV，隱含波動率）

- **定義**：市場對未來波動幅度的預期，嵌入在選擇權定價中
- **IV 高**：市場預期大波動（如財報前）→ 選擇權 premium 貴 → 適合**賣方策略**
- **IV 低**：市場預期穩定 → 選擇權 premium 便宜 → 適合**買方策略**

### IV Crush（波動率崩潰）

```
財報前：不確定性高 → IV 飆升 → 選擇權變貴
財報後：不確定性消除 → IV 暴跌 → 選擇權變便宜

無論財報結果好壞，IV 都會下跌
→ 賣方（收取 premium 者）受益，買方受損
```

**利用方式**：在財報前賣出選擇權（收取高 premium），財報後 IV 崩潰，以更低價買回平倉獲利。

### Delta（Δ）

- 衡量選擇權價格對標的股票 $1 變動的敏感度
- Delta 0.30 ≈ 勝率約 30% 的價外（OTM）選擇權
- **Delta 中性**：組合 Delta 接近 0，對方向性移動影響最小

## 策略一：Trailing Stop（移動停損）

**定義**：停損點跟著最高價自動上移，鎖住已有獲利。

```
買入價：$100
設定 Trailing Stop：$5

股價漲至 $110 → 停損點移至 $105
股價漲至 $120 → 停損點移至 $115
股價從 $120 跌至 $114 → 觸發出場，獲利 $14

（若使用固定停損，停在 $95，獲利 $0 卻早就能出在 $115）
```

**優點**：讓獲利奔跑，同時保護下行  
**缺點**：正常波動可能提前觸發

## 策略二：Credit Spread vs Debit Spread

### Credit Spread（信用價差）

```
賣出較貴的選擇權 + 買入較便宜的選擇權
→ 開倉時淨收入 Premium（Credit）
→ 適合 IV 高時使用（Premium 貴，有利可圖）
```

**風險**：有上限（兩腳 strike 差 - 收到的 premium）

**Call Credit Spread（看跌時）**：
```
Sell Call 200（收 Premium）
Buy Call 210（買保護）
→ 股價漲超 200 時開始虧損，210 以上最大虧損
```

**Put Credit Spread（看漲時）**：
```
Sell Put 190（收 Premium）
Buy Put 180（買保護）
→ 股價跌破 190 時開始虧損，180 以下最大虧損
```

### Debit Spread（借方價差）

```
買入較貴的選擇權 + 賣出較便宜的選擇權
→ 開倉時淨付出 Premium（Debit）
→ 適合 IV 低時使用（相對便宜的 Premium）
```

**範例**：Microsoft Debit Call Spread（Buy 430 / Sell 455）
```
期望值：$3.77
勝率：49.2%
最大獲利：$1,646
最大虧損：$854
```

## 策略三：Iron Condor（鐵鷹式）

### 結構

四腳策略，同時做 Put Credit Spread + Call Credit Spread：

```
        ┌─────────────────────────────┐
        │                             │ 最大獲利區（收取 premium）
 ───────┤ Buy Put   Sell Put  Sell Call   Buy Call ├───────
        │                             │
        └─────────────────────────────┘
        Max Loss    ← 獲利區 →    Max Loss
```

**適用情境**：
- 財報後（IV Crush）
- 預期股價在特定區間內震盪
- 市場中性，不判斷方向

**損益結構**：
| 情境 | 結果 |
|------|------|
| 股價在兩個 Sell strike 之間到期 | 獲利 = 全部收取的 premium |
| 股價超出任一側 | 開始虧損 |
| 股價超出外側 Buy strike | 最大虧損（有限，兩 strike 差 - premium） |

**範例**：Amazon Iron Condor（財報前）
```
Sell Put 240 / Buy Put 232.5   （下方 Put Spread）
Sell Call 265 / Buy Call 272.5  （上方 Call Spread）
到期日：7–21 天

收取 Premium：$369（最大獲利）
損益兩平：$238–$270
最大虧損：$3,100
勝率：~40%
```

⚠️ 風報比警示：勝率 40%，Max Loss / Max Profit = 8.4x，需要高勝率長期維持才能正期望值。

## 策略四：方向性選擇權掃描框架

AI 自動篩選的決策邏輯：

```
判斷趨勢方向
    ↓
查 IV 水準
    ├─ IV 高 → Credit Spread（賣方收 premium）
    └─ IV 低 → Debit Spread（買方期待大幅移動）
    ↓
篩選條件：
  - 到期日 30–45 天
  - 第一腳 Delta ≈ 0.30
  - 第二腳在股價 3% 範圍內
  - 期望報酬率達標
  - 勝率（PoP）達標
    ↓
出場目標：收取 premium 的 50%（不貪心，降低 Gamma 風險）
```

## 關鍵指標速查

| 指標 | 說明 | 使用情境 |
|------|------|---------|
| IV | 隱含波動率 | 高→賣，低→買 |
| Delta (Δ) | 方向性敏感度 | 0.30 = 適中風險的 OTM |
| PoP | 勝率（Probability of Profit）| 評估策略合理性 |
| Premium | 選擇權價格 | Credit Spread 收入 |
| Breakeven | 損益兩平點 | 計算緩衝區間 |
| Max Loss | 最大虧損（有限）| 資金管理計算 |
