# 股票術語大全

## 市場行情術語

| 術語 | 定義 |
|------|------|
| **多頭（牛市）** | 股價持續上漲，市場熱絡 |
| **空頭（熊市）** | 股價持續下跌，市場低迷 |
| **大盤** | 台灣加權股價指數，代表整體市場表現 |
| **漲停** | 股價上漲達 +10%，停止接受更高買單 |
| **跌停** | 股價下跌達 -10%，停止接受更低賣單 |
| **開盤價** | 當日第一筆成交價 |
| **收盤價** | 當日最後一筆成交價（最能反映當日行情） |
| **成交量** | 買賣雙方達成交易的總股數（單位：張） |

## 買賣操作術語

| 術語 | 定義 |
|------|------|
| **做多** | 買進股票，預期股價上漲獲利 |
| **做空** | 借股票賣出，預期股價下跌後低價買回 |
| **融資** | 向券商借錢買股票（利率約 6%/年），等同槓桿 |
| **融券** | 向券商借股票來賣出（做空工具），需繳交保證金 |
| **平倉** | 結清持有的多頭或空頭部位 |
| **套牢** | 股價下跌、賣出會虧損，被迫長期持有 |
| **停損** | 在虧損達到預設幅度時認賠賣出，控制損失 |
| **停利** | 在獲利達到預設幅度時獲利了結 |

## 交易行為術語

| 術語 | 定義 |
|------|------|
| **買超** | 特定期間買股 > 賣股，市場偏多 |
| **賣超** | 特定期間賣股 > 買股，市場偏空 |
| **抄底（接刀）** | 股價大跌後進場，風險高（「摸底是刀，越摸越深」） |
| **軋空** | 做空的人被迫回補，推動股價暴漲 |
| **跳空** | 開盤價與前日收盤價之間出現缺口（gap） |
| **破底** | 股價跌破前低支撐，常是空頭訊號 |
| **飆股** | 短期內連續漲停的股票 |
| **主力** | 持有大量資金，能影響個股股價的大戶 |
| **韭菜** | 資金少、容易被主力收割的散戶投資人 |

## 財務報表術語

| 術語 | 定義 | 公式 |
|------|------|------|
| **EPS**（每股盈餘）| 公司每股賺多少錢 | 稅後淨利 ÷ 在外流通股數 |
| **P/E**（本益比）| 回本需要幾年？ | 股價 ÷ EPS |
| **P/B**（股價淨值比）| 股價是帳面價值的幾倍？ | 股價 ÷ 每股淨值 |
| **ROE**（股東權益報酬率）| 用股東的錢賺了多少？ | 稅後淨利 ÷ 股東權益 |
| **ROA**（總資產報酬率）| 所有資產的使用效率 | 稅後淨利 ÷ 平均總資產 |
| **殖利率** | 投資報酬率（以股息計算） | 現金股利 ÷ 股價 |
| **淨值** | 公司的帳面價值（資產－負債） | 股東權益總額 |

## 股利術語

| 術語 | 定義 |
|------|------|
| **現金股利** | 公司以現金形式配發給股東的盈餘 |
| **股票股利** | 公司以增發股票方式配發（增加持股數，但每股價值稀釋） |
| **除息** | 發放現金股利的基準日，股價當日等額下跌 |
| **除權** | 發放股票股利的基準日，股數增加但股價等比下調 |
| **填息（填權）** | 除息（除權）後股價回升至原水準，才算真正獲利 |
| **貼息（貼權）** | 除息（除權）後股價無法回升，實際上是虧損 |

## 公司行動術語

| 術語 | 定義 |
|------|------|
| **增資** | 公司發行新股籌募資金，可能稀釋現有股東權益 |
| **減資** | 公司縮減股本（退還現金給股東，或彌補虧損） |
| **法說會** | 法人說明會，公司向機構投資人說明營運狀況 |
| **法會** | 俗稱，指發布利多消息後股價反而大跌的法說會 |

## 指數與市場結構術語

| 術語 | 定義 |
|------|------|
| **加權指數** | 台灣所有上市公司依市值加權的股價指數 |
| **外資** | 外國機構投資人（影響力最大，約佔市場 23%） |
| **投信** | 本國投資信託公司（約佔 1%） |
| **自營商** | 國內券商自行買賣（約佔 6%） |
| **融資餘額** | 市場上投資人借錢買股的總金額（高時代表市場過熱） |
| **融券餘額** | 市場上投資人借股賣出的總數量（高時代表空頭壓力大） |
