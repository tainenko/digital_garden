# 法院調查證據程序

## 三階段順序（不可逆）

```
① 確認證據能力（能否進入法庭？）
    ↓
② 法院調查證據（以合法程序取得心證素材）
    ↓
③ 評價證明力（是否達積極證據標準？）
    ↓
④ 認定待證事實 → 有罪 / 無罪
```

## 聲請調查證據三標準

法院得裁定駁回不符合以下三標準的聲請：

| 標準 | 說明 |
|------|------|
| **可能性** | 該證據確實可能存在 |
| **關聯性** | 與[[待證事實]]有直接或間接關聯 |
| **必要性** | 對案件裁判有實質影響 |

## 調查方法

### 物證
- 審判長將實物**提示**給當事人辨認
- 文書性物證：說明內容後再提示

### 書證
- **朗讀全文**或**告知要旨**
- 涉及風化、公序良俗或當事人名譽者：改以**不公開方式**（閉庭）處理

### 人證（詰問程序）
| 階段 | 主體 | 內容 |
|------|------|------|
| 主詰問 | 聲請調查方 | 建立有利事實 |
| 反詰問 | 他方當事人 | 挑戰可信度 |
| 覆主詰問 | 聲請調查方 | 修復主詰問損傷 |
| 補充詰問 | 法官 | 補充釐清 |

## 法院職權調查
- 當事人聲請的證據不足時，法院得**依職權**主動調查
- 程序上應**先令檢察官聲請**，不足時方自行介入（維持控辯對等）
- 特別注重對被告有利的事實（[[無罪推定原則]]延伸）

## 調查結束後
每次證據調查完畢，審判長須：
1. 詢問當事人對該證據的**意見**
2. 告知被告有提出有利證據的**權利**（但無義務）

## 法律依據
- 刑事訴訟法第 95 條：告知被告權利
- 刑事訴訟法第 155 條：自由心證與[[證據能力]]
- 刑事訴訟法第 163–166 條：聲請調查、職權調查、詰問程序
- 刑事訴訟法第 288 條：審判調查程序
