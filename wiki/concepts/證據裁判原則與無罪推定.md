# 證據裁判原則與無罪推定原則

## 一、證據裁判原則（Evidence Adjudication Principle）

### 定義
> 「犯罪事實應依證據認定之，無證據不得認定犯罪事實。」（刑事訴訟法第154條第2項）

所有定罪的事實認定，**必須以證據為基礎**。法官不得依猜測、印象或未經調查的陳述認定犯罪事實。

### 意涵
- 證據必須先具備[[證據能力]]（能進入法庭），再評價其[[證明力]]（說服強度）。
- 達到[[積極證據]]標準（超越合理懷疑）方可定罪。
- 未達標準 → 無罪（不是「尚未確定有罪」，而是應積極判決無罪）。

## 二、無罪推定原則（Presumption of Innocence）

### 定義
被告在法院有罪判決確定前，推定為無罪。

### 舉證責任分配

| 角色 | 舉證責任 |
|------|---------|
| 檢察官 / 告訴人 | 積極提出[[積極證據]]，打破無罪推定 |
| 被告 | **無須自證清白**；對阻卻事由提出合理懷疑即可 |
| 法院 | 依[[自由心證原則]]綜合評價，存疑時應為無罪 |

### 疑點利益歸被告原則
當[[積極證據]]不足，或尚有合理懷疑時：
- 不得以「尚未排除犯罪可能性」為由定罪
- 應判決**無罪**（不是無法判斷，而是法律要求判無罪）

## 兩原則的關係

```
無罪推定（起點）
    → 檢察官提出積極證據
    → 法院依證據裁判原則審查
    → 達到超越合理懷疑 → 有罪
    → 未達標準 → 維持無罪推定 → 無罪判決
```

## 法律依據
- 刑事訴訟法第 154 條：證據裁判原則、無罪推定
- 刑事訴訟法第 163-1、163-2 條：當事人聲請調查證據
