# 加密量化基礎設施（Crypto Quant Infrastructure）

## 最小可行技術棧

| 組件 | 說明 |
|------|------|
| **交易所 API** | 多交易所 REST + WebSocket，含故障轉移（failover） |
| **節點接入** | 歸檔以太坊節點，或 RPC 服務（Alchemy/QuickNode）|
| **行情監控** | API 錯誤率、清算瀑布預警、穩定幣價差、橋 TVL 異動 |
| **私鑰管理** | **3-of-5 多簽**，地理隔離簽名者 |
| **KYC/AML** | Chainalysis / TRM / Elliptic（合規用） |
| **緊急熔斷** | 自動 kill-switch：失控進程可在人類醒來前蒸發資金 |

## 監控指標清單

**必監控**：
- 各交易所保證金比率（觸發 ≤ 55% 警報，≤ 50% 自動減倉）
- 穩定幣價差（USDC/USDT 脫錨 >0.5% 即預警）
- 橋 TVL 異常下降（>10% 30分鐘內）
- API 錯誤率（>5% 觸發降級模式）
- Gas 費用飆升（鏈上套利成本驟增）

## 安全架構

```
冷錢包（離線簽名）
    ↓ 定期轉帳
熱錢包（交易執行）── 3-of-5 多簽閾值
    ↓ 有限授權
DEX 授權（設定每日最大消費上限）
```

**FTX 教訓**：勿在交易所保留超過即時交易需要的資金。主倉庫在自託管冷錢包；交易所只存當日交易所需的流動性緩衝。

## 團隊配置（$1B AUM 規模）

| 職能 | 人數 |
|------|------|
| DevOps/節點管理 | 2–3 人 |
| 安全/冷錢包 | 2 人 |
| 合規/AML | 2 人 |
| 研究/策略 | 4–6 人 |
| 執行/做市 | 3–5 人 |
| **合計** | **13–18 人** |

## 24/7 運維挑戰

- 加密市場**永不休市**，傳統股市的「休假後再處理」不適用
- 自動熔斷機制必須能應對所有可預見的異常狀態
- 建立明確的 On-call 輪班制度和事件響應手冊（Runbook）
- 測試環境必須能模擬高波動率場景（如 2024-08-05 閃崩）

## 合規邊界（主要司法管轄）

| 地區 | 合規要求 |
|------|---------|
| 歐盟 | MiCA（Markets in Crypto-Assets）VASP 許可 |
| 香港 | SFC VASP 許可（2023年起強制） |
| 日本 | FSA 交易所牌照 |
| 新加坡 | MAS 數字支付代幣服務許可 |
| 美國 | SEC（證券）+ CFTC（期貨/衍生品）雙重監管 |
| 中國大陸 | 2021-09 以後：個人加密貨幣交易列為「非法金融活動」|
