# 資金費率套利（Funding Rate Arbitrage）

## 機制

永續合約（Perpetual Futures）使用定期資金費率讓價格錨定現貨指數。當多頭多於空頭時，多頭支付空頭；反之亦然。

**核心做法**：
- Long 現貨 + Short 永續合約 → delta-neutral 頭寸
- 持倉期間持續收取正向資金費率
- 並捕獲基差（basis）收斂的套利空間

## 關鍵參數

| 參數 | 典型值 |
|------|--------|
| 資金費率週期 | 每 8 小時一次 |
| 單次費率 | ~0.01%（年化約 10.95%）|
| 基差（Basis） | 5–30 bps |
| 預期年化報酬 | **8–30%** |

## 實作重點

- 使用 [[ccxt]] 掃描多交易所資金費率，計算年化收益率
- 監控基差是否擴大（觸發入場）或壓縮（觸發出場）
- 需同時維護現貨與合約帳戶的保證金比率（建議保持 ≥50%）

## 風險

| 風險 | 說明 |
|------|------|
| 交易所對手方風險 | FTX 崩潰案例——資產不隔離，交易所倒閉即損失全部 |
| 極端行情強制平倉 | 2024-08-05 BTC 單日 -17%，觸發大量清算 |
| 資金費率轉負 | 牛市反轉時費率可能轉為空頭付多頭 |
| 流動性風險 | 小幣種現貨-合約套利的深度不足 |

## 投資組合定位

- **推薦配置**：30–40%（最高單一策略上限）
- 屬於最成熟、容量最大（BTC 可達十億美元級）的 delta-neutral 策略
- 與 [[無常損失與AMM流動性提供]] 互補：AMM 承擔波動率風險，本策略迴避
