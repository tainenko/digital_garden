# 無常損失與 AMM 流動性提供

## AMM 收益來源

1. **交易手續費分配**（0.05%–1%，依池子而異）
2. **協議 token 激勵**（如 UNI、SUSHI）
3. **價格波動再平衡**收益（理論上，實際常為負）

## 無常損失（Impermanent Loss）

### 公式

$$IL(r) = \frac{2\sqrt{r}}{1+r} - 1$$

其中 r = 價格比值變化（最終價格 / 初始價格）

### 典型數值

| 價格變化 | 無常損失 |
|----------|----------|
| ±25% | -0.6% |
| ±50% | -2.0% |
| ±100%（翻倍） | **-5.7%** |
| ±200% | **-13.4%** |
| ±300% | **-20.0%** |

### 關鍵認知
- **IL 是與「純持有」相比的損失**，非絕對損失
- 費用收入 + token 激勵必須超過 IL 才能淨正報酬
- **IL 只有在提款時才「實現」**，持倉期間是浮動損失

## Uniswap V3 集中流動性

- 允許 LP 指定價格區間，在區間內資本效率大幅提升
- 但需**主動再平衡**，否則價格移出區間後手續費收入歸零
- 經濟上等同於**賣出波動率（Short Volatility）**：波動越大 IL 越嚴重

## 淨報酬評估框架

```
淨年化報酬 = 手續費年化 + Token 激勵年化 - 無常損失年化
```

- **若 token 激勵為主要收益來源**：需評估 token 長期可持續性（農耕代幣歷史上多數歸零）
- 穩定幣池（如 USDC/USDT）IL 接近零，但費率較低

## 穩定幣 AMM（[[Curve Finance]]）

Curve 使用改良的 StableSwap 公式，針對 1:1 錨定資產大幅降低滑點。由於資產維持近似恆定價格，IL 極低，是穩定幣 LP 的主流選擇。詳見 [[Curve-Convex收益策略]]。

## 風險

| 風險 | 說明 |
|------|------|
| 智能合約漏洞 | 協議本身被攻擊 |
| Token 激勵崩潰 | 農耕幣價格暴跌 |
| 市場波動 | IL 迅速擴大 |
| 流動性提取 | 其他 LP 提走流動性後滑點上升 |
