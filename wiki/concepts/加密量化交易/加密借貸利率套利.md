# 加密借貸利率套利

## 機制

跨 DeFi 借貸協議（Aave、Compound、Venus 等）捕獲利差：

```
協議 A 存款利率 8% APY
      - 協議 B 借款利率 5% APY
      = 淨利差 3%（扣除 gas 費、清算緩衝後的實際報酬）
```

## 典型操作流程

1. 在高利率協議存入穩定幣（如 USDC），收取存款利率
2. 在低利率協議以其他資產作為抵押品，借出穩定幣或其他資產
3. 反覆循環直至 LTV 接近但不觸發清算線

## 核心風險：清算

DeFi 借貸協議在**抵押率跌破 LTV 閾值**（通常 80–90%）時自動清算：

| 觸發因素 | 說明 |
|----------|------|
| 抵押品價格暴跌 | 抵押物（ETH/BTC 等）下跌使 LTV 惡化 |
| 借入資產價格上漲 | 借 stETH 時遭遇 LST 溢價 |
| 協議清算 penalty | 通常 5-15% 的清算懲罰 |

**2022年6月 stETH 去錨事件**：stETH 一度跌至 0.94 ETH，大量以 stETH 作抵押借 ETH 的頭寸面臨清算瀑布風險。

## 可持續性評估

- **利差壓縮**：Alpha 被套利後快速消失，需持續監控多協議利率差
- **真實收益 vs Token 補貼**：高達 50%+ APY 的「借貸激勵」多為協議方補貼，假設補貼代幣歸零來評估可持續性
- 推薦配置：10–20%（見 [[加密量化投資組合配置]]），LTV 上限 40%

## 風險清單

| 風險 | 緩解措施 |
|------|---------|
| 清算 | LTV ≤ 40%，設置自動補倉警報 |
| 利差縮窄 | 監控多協議利率，設定最小利差閾值退出 |
| 智能合約漏洞 | 分散多協議，單協議敞口上限 |
| 流動性危機 | 維持足夠穩定幣現金儲備（20-30%）快速補充抵押 |
