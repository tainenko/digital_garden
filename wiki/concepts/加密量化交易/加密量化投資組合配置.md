# 加密量化投資組合配置框架

## 推薦風險預算分配

| 策略 | 推薦配置 | 特性 |
|------|----------|------|
| [[資金費率套利]]（delta-neutral） | **30–40%** | 最成熟，容量大，年化 8-30% |
| AMM LP（主流幣對 + 穩定幣）| **20–30%** | 需承擔 IL 風險 |
| 借貸利差（[[加密借貸利率套利]]）| **10–20%** | LTV 上限 40% |
| 跨交易所/三角套利 | **10%** | 機構競爭激烈，容量小 |
| 現金儲備（穩定幣） | **20–30%** | 應急、補倉、機會性部署 |

## 硬性集中度上限

| 維度 | 上限 |
|------|------|
| 單一策略 | **≤ 40%** |
| 單一交易所 | **≤ 30%**（FTX 教訓） |
| 單一代幣敞口 | **≤ 20%** |
| 永續合約保證金比率 | **≥ 50%** |
| 借貸 LTV | **≤ 40%** |

## 容量 vs 報酬反比法則

策略的容量與報酬**嚴格反比**：

```
高報酬（50%+） → 容量 $100K–$1M  → MEV、小幣套利
中報酬（20–50%） → 容量 $1M–$10M → 新興 DeFi 池、小幣資金費率
低報酬（8–20%） → 容量 $1B+     → BTC/ETH 資金費率、主流穩定幣 LP
```

**意涵**：資金規模擴大後，必然向低報酬高容量策略移動。

## 策略衰減管理

- 加密因子**半衰期 6-12 個月**（vs 股票 5+ 年）
- 每季度重新評估各策略的 alpha 是否仍存在
- 建立研究管道：持續發現新策略以替代衰減的舊策略

## 歷史黑天鵝事件的啟示

| 事件 | 教訓 |
|------|------|
| FTX 崩潰 (2022-11) | 單一交易所集中度上限是生死線，而非理論指引 |
| stETH 去錨 (2022-06) | 抵押品同質化 → 系統性清算瀑布 |
| USDC 去錨 (2023-03，最低 0.87) | 穩定幣儲備必須多元化（SVB 風險） |
| 2024-08-05 閃崩 | BTC 單日 -17%，$100B+ 清算；高槓桿的日元套利平倉引發 |

## 核心原則

> **「生存本身即 alpha。」** 避免交易所倒閉、橋接被盜、清算瀑布，比追求邊際 bps 更重要。
