# 台灣法規違規檢舉指南

## 概覽

本分類整理台灣食品、美妝、健康食品等領域的相關法規，聚焦於**設有檢舉獎金機制**的項目，協助辨識市面上產品或廣告的潛在違規。

---

## 主要法規範圍

| 法規 | 主管機關 | 常見違規類型 | 是否有檢舉獎金 |
|------|---------|------------|--------------|
| [[食品安全衛生管理法]] | 衛福部食藥署（TFDA） | 標示不實、禁用添加物、誇大宣稱 | ✅ 罰鍰 5–20% |
| [[化粧品衛生安全管理法]] | 衛福部食藥署 | 宣稱醫療效能、禁用成分、標示不完整 | ✅（依各地衛生局） |
| [[健康食品管理法]] | 衛福部食藥署 | 未取證宣稱療效、冒用小綠人標章 | ✅ |
| [[藥事法]] | 衛福部食藥署 | 非藥品宣稱療效（以食品／美妝包裝） | ✅ |
| [[公平交易法]] | 公平交易委員會 | 不實廣告、誤導消費者 | ✅ 罰鍰 10–20% |

---

## 檢舉獎金制度概要

### 食品安全衛生管理法（第 49 條之 1）

- **獎金比例**：核課罰鍰的 **5%–20%**
- **受理單位**：衛福部食藥署 / 各縣市衛生局
- **條件**：需提供具體事證（產品照片、購買憑證、廣告截圖等）
- **保密**：主管機關應為檢舉人保密身分

### 公平交易法（第 47 條之 1）

- **獎金比例**：裁處罰鍰的 **10%–20%**
- **受理單位**：公平交易委員會（公平會）
- **適用**：不實廣告、仿冒、欺罔消費者

## 常見違規辨識重點

### 一、廣告宣稱違規

| 違規類型 | 說明 | 適用法規 |
|---------|------|---------|
| 食品宣稱療效 | 非藥品宣稱治療、預防疾病 | 食安法、藥事法 |
| 化妝品宣稱醫療效能 | 如宣稱「改善黑斑」「治療痘痘」 | 化粧品法、藥事法 |
| 未取證健康食品標示功效 | 未獲小綠人認證卻宣稱功效 | 健食法 |
| 誇大不實數據 | 「100% 有效」「臨床證實」無科學根據 | 食安法、公平交易法 |

### 二、標示違規

| 違規類型 | 說明 | 適用法規 |
|---------|------|---------|
| 成分標示不完整 | 未列全成分、使用不正確名稱 | 食安法、化粧品法 |
| 有效日期標示錯誤 | 塗改、未標示 | 食安法 |
| 輸入商品未中文標示 | 進口商品無繁體中文完整標示 | 食安法、化粧品法 |
| 製造商資訊缺漏 | 未標示製造商地址、負責廠商 | 食安法 |

### 三、成分違規

| 違規類型 | 說明 | 適用法規 |
|---------|------|---------|
| 使用禁用添加物 | 如塑化劑、非法色素 | 食安法 |
| 化妝品禁用成分 | 如超標重金屬、禁用防腐劑 | 化粧品法 |
| 宣稱成分與實際不符 | 標示含有效成分但實際無 | 食安法、公平交易法 |

## 分析連結的標準流程

當用戶提供產品頁面或廣告連結時，依以下步驟分析：

```
1. 讀取內容
   └─ 擷取：產品名稱、成分標示、廣告文字、宣稱效果、價格、製造商

2. 對照法規
   ├─ 判斷產品類型（食品/化妝品/健康食品/藥品）
   ├─ 逐條比對廣告宣稱是否逾越允許範圍
   └─ 確認標示是否符合最低法規要求

3. 產出分析報告（見下方模板）
```

### 分析報告模板

```markdown
## 產品：[產品名稱]
**來源連結**：[URL]
**分析日期**：YYYY-MM-DD
**產品類型**：食品 / 化粧品 / 健康食品 / 藥品 / 其他

### 可能違規項目

| # | 違規內容 | 原文 / 截圖說明 | 違反法條 | 嚴重程度 |
|---|---------|---------------|---------|---------|
| 1 | | | | 高/中/低 |

### 建議檢舉管道

- [ ] 食藥署網路申辦（1919）
- [ ] 各縣市衛生局
- [ ] 公平交易委員會

### 所需蒐證清單

- [ ] 產品照片（正面、背面、成分標示）
- [ ] 購買憑證
- [ ] 廣告截圖（含 URL、日期）

### 結論

[整體評估：違規可能性高/中/低，建議後續行動]
```
