# Claude 股市與期貨分析實戰

> 兩種截然不同的使用模式：一是**直接分析**（貼資料讓 Claude 解讀），二是**Vibe Coding 建系統**（讓 Claude 寫分析工具）。兩者要清楚區分，混用是最常見的認知誤區。

---

## 兩種模式的邊界

```
模式 A：直接分析（Claude 作為分析師）
  你 → 貼入資料（財報、K線數值、新聞） → Claude 解讀 → 你決策

模式 B：Vibe Coding 建工具（Claude 作為工程師）
  你 → 描述需求 → Claude 寫程式 → 程式自動跑資料 → 你看結果

關鍵差異：
  - 模式 A 的輸出是「文字分析」，一次性消耗
  - 模式 B 的輸出是「可重複執行的程式」，長期資產
  - 模式 A 適合深度個案分析；模式 B 適合批量掃描、自動化
```

---

## 模式 A：直接讓 Claude 分析

### 技術分析解讀

**適合貼給 Claude 的資料格式：**

```
日期,開盤,最高,最低,收盤,成交量
2026-04-01,185.5,188.2,184.0,187.3,45230
2026-04-02,187.3,190.1,186.5,189.8,52100
...（20-60 根 K 線即可）
```

**Prompt 模板：**

```
以下是台積電（2330）最近 30 個交易日的日 K 資料：
[貼入 CSV]

請分析：
1. 目前趨勢方向與強度（用均線關係判斷）
2. 關鍵支撐與壓力位
3. 近期有無型態（底部、頭肩、旗形等）
4. 成交量是否配合價格方向
5. 給出一個最可能的後續走法情境（含否定該情境的條件）

請只描述你在資料中實際看到的，不要給投資建議。
```

**期貨專用補充（加在 prompt 末尾）：**

```
另附未平倉量（OI）資料：
日期,結算價,OI變化,多空力道
...

請額外分析：
- OI 增減與價格方向的配合程度（多方增倉 or 空方增倉）
- 是否有軋空或逼多跡象
```

---

### 基本面財報分析

**Prompt 模板（適合貼入財報 PDF 文字或公告）：**

```
以下是[公司名]最新一季財報摘要：
[貼入財報數字或文字段落]

請計算並解讀：
1. 毛利率、營業利益率、淨利率的季度變化趨勢
2. ROE 分解（杜邦分析：淨利率 × 資產周轉 × 財務槓桿）
3. 現金流狀況（自由現金流 = 營業現金流 - 資本支出）
4. 與上一季、去年同期的比較
5. 有無異常科目需要關注（如應收帳款暴增、存貨堆積）

請用表格整理關鍵指標，最後給出 2-3 個需要進一步確認的問題。
```

---

### 籌碼分析（台股）

**三大法人資料 Prompt：**

```
以下是[股票]近 20 個交易日的三大法人買賣超資料：
日期,外資買賣超,投信買賣超,自營商買賣超,收盤價
...

請分析：
1. 外資最近的方向性（連續買超/賣超幾日？）
2. 投信與外資是否同向（同向信號較強）
3. 籌碼集中度趨勢（大戶是否持續加碼？）
4. 有無「主力建倉完成後散戶追入」的分布跡象
```

---

### 期貨 COT 報告分析（海外期貨）

```
以下是 [商品/指數] 的 COT 報告數據：
日期,大戶多單,大戶空單,散戶多單,散戶空單,淨多空
...

請分析：
1. 大戶（商業戶/非商業戶）目前淨部位方向
2. 與歷史極值相比，目前淨多空處於什麼百分位？
3. 散戶與大戶的方向是否相反（反向指標）？
4. 過去 4-8 週趨勢的方向變化
```

## 模式 B：Vibe Coding 建分析工具

### 資料獲取層

**台灣股市推薦資料源：**

| 資料類型 | 推薦套件/API | 備註 |
|---------|------------|------|
| 台股歷史 K 線 | `twstock`、`FinMind` | FinMind 有 API key 限制 |
| 即時報價 | `fugle-realtime`（富果 API）| 需開戶 |
| 三大法人 | `FinMind` / 證交所 opendata | 官方 CSV 可直接下載 |
| 財報數據 | `FinMind`、`TEJ`（付費） | TEJ 最完整 |
| 台指期 | 期交所 OpenAPI / `FinMind` | 含逐筆交易資料 |

**海外市場：**

| 資料類型 | 推薦套件/API |
|---------|------------|
| 美股/ETF | `yfinance`（免費）、`polygon.io`（付費） |
| 加密貨幣 | `ccxt`（100+ 交易所統一介面） |
| 期貨 COT | CFTC 官方網站 CSV |
| 總經數據 | `fredapi`（美聯儲 FRED 免費） |

**讓 Claude 寫下載 script 的 Prompt：**

```
幫我寫一個 Python script，用 yfinance 下載台積電（TSM）
過去 2 年的日 K 資料，存成 CSV。
欄位需要包含：日期、OHLCV、20MA、60MA、RSI(14)、MACD。
不需要畫圖，只需要輸出 CSV。
```

### 建立個股掃描器（Screener）

**Prompt 範例：**

```
幫我寫一個台股技術面掃描器，使用 FinMind API 或 twstock。

掃描條件（AND 關係）：
- 收盤價站上 20 日均線
- 20 日均線向上斜（今日 MA20 > 5日前 MA20）
- 成交量 > 20 日均量的 1.5 倍
- 股價 > 30 元（排除雞蛋水餃股）
- RSI(14) 在 50-70 之間（非超買）

輸出：符合條件的股票清單，含當日收盤價、成交量比、RSI 值。
每天可以跑一次，把結果存到 results/YYYYMMDD.csv。

請用 pandas 處理，不要用任何需要 API key 的付費服務。
```

### 建立期貨分析工具

**價差分析（近遠月 / 期現貨）Prompt：**

```
幫我寫一個台指期基差（期現貨價差）分析工具：

1. 從 FinMind 拉取台指期近月合約結算價（TX 系列）
2. 從 TWSE opendata 拉取加權指數收盤
3. 計算每日基差 = 期貨結算價 - 現貨收盤
4. 計算 20 日平均基差作為基準
5. 輸出：基差時序圖 + 當前基差所在百分位（過去一年）

當基差偏離均值 > 1 個標準差時，在圖上標注。
用 matplotlib 繪圖，存成 PNG。
```

**未平倉量分析 Prompt：**

```
幫我寫一個台指期三大法人未平倉分析工具：

資料來源：期交所 opendata（每日更新 CSV）
URL 格式：https://www.taifex.com.tw/cht/3/futContractsDate

分析內容：
1. 外資期貨淨部位（多單 - 空單）時序圖
2. 外資選擇權 Put/Call 比（隱含市場偏多/偏空）
3. 自營商期貨淨部位（自營商常扮演造市者，反向參考）
4. 顯示最近 60 個交易日資料

用 requests + pandas 處理，matplotlib 繪圖。
```

### 回測分析工具

**讓 Claude 建立基礎回測框架的安全 Prompt：**

```
幫我建立一個簡單的策略回測框架（不是優化器，只是驗證器）。

框架需求：
- 輸入：OHLCV DataFrame + 信號 Series（1=多頭進場, -1=空頭進場, 0=無）
- 信號由我自己另外計算後傳入（框架不負責產生信號）
- 計算指標：總報酬率、年化報酬率、最大回撤、勝率、獲利因子（Profit Factor）
- 假設每次進出手續費 0.1425% 雙邊
- 輸出：指標表格 + 資金曲線圖

重要：這個框架只做計算，不要自動建議優化參數。
信號邏輯我會自己寫，不要幫我「改進」或「優化」信號部分。
```

> 注意：信號產生邏輯永遠由人類掌控（對應 [[Vibe Coding程式交易實戰]] 的 strategy/core 保護原則），回測框架只是「計算機」。

## Claude 分析的限制與邊界

### 不能做的事

```
✗ 即時報價分析（Claude 沒有市場即時資料）
✗ 自動下單執行（Claude 不能連接 broker API）
✗ 預測未來價格（沒有人能做到，Claude 也不例外）
✗ 替代專業投資顧問（任何 AI 分析都不構成投資建議）
✗ 分析數年前的最新新聞（知識截止日期限制）
```

### 正確使用邊界

```
✓ 根據你提供的資料做結構化解讀
✓ 寫資料處理和分析的程式碼
✓ 解釋財務指標的計算方式與含義
✓ 幫你思考假設條件（"如果 OI 繼續增加，代表..."）
✓ 整理分析框架和思考清單
✓ 審查你的程式邏輯（不改策略邏輯）
```

## 分析工作流範例

### 台股個股分析流程

```
1. 資料收集（Vibe Coding）
   → Claude 寫 script 下載 K 線 + 三大法人 + 財報摘要

2. 初步篩選（Vibe Coding）
   → Claude 寫 screener 跑出候選清單

3. 深度分析（直接分析）
   → 把候選股資料貼給 Claude，要求結構化解讀

4. 交叉驗證（你自己）
   → 你親自看圖、確認邏輯、結合產業認知

5. 結論輸出（直接分析）
   → 讓 Claude 幫你整理分析摘要（但決策是你）
```

### 台指期交易分析流程

```
每日例行（Vibe Coding 自動執行）：
  → 下載三大法人期貨部位、OI 變化、基差
  → 輸出每日報表 CSV

盤前分析（直接分析）：
  → 貼昨日數據 + 美期走勢給 Claude
  → Prompt："今天台指期的多空格局，根據以下數據..."

週末覆盤（直接分析）：
  → 貼入一週資料，要求 Claude 整理本週關鍵籌碼變化
```

## Prompt 品質關鍵原則

### 給分析類 Prompt 的準則

```
1. 給資料，不給預設立場
   ✗ "台積電要漲了對嗎？以下資料..."
   ✓ "請根據以下資料分析台積電目前的多空格局..."

2. 明確指定分析框架
   ✓ "請用 OHLCV + 均線 + 成交量三個維度分析"
   ✓ "請用杜邦分析框架解讀以下財報"

3. 要求列出否定條件
   ✓ "給出最可能的走法，並列出讓你改變看法的條件"

4. 限制輸出範圍
   ✓ "只描述你在資料中看到的，不要外推未來"
   ✓ "不要給買賣建議，只做事實描述"
```

### 給程式碼類 Prompt 的準則

```
1. 指定資料來源（避免 Claude 自己選擇不熟悉的 API）
2. 指定輸出格式（CSV / 圖表 / console）
3. 明確說「信號邏輯我自己寫」
4. 說明環境（Python 版本、已安裝的套件）
```
