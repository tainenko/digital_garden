# IG 輪播轉換設計

## 核心定位

輪播貼文（Carousel）在 IG 個人品牌中的角色：

```
短影音 → 吸引注意（觸及陌生人）
輪播   → 建立信任（讓人停下來理解你）
限時動態 → 維持關係（與既有粉絲互動）
```

> 輪播的核心價值不是「被看見」，而是把「被看見」轉化為「被信任」，再推進到「願意付費」。

— [[growithfyn]]，1.1 萬留言爆紅貼文

---

## 輪播為何能建立信任

短影音無法做到、但輪播做得到的事：

```
短影音：
✅ 觸及廣、注意力強
❌ 時間短，難以傳遞完整邏輯
❌ 看完即走，無法引導下一步

輪播：
✅ 承載結構——可以一步步展開論述
✅ 讀者主動滑動 = 主動投入
✅ 每一張都是一個「決策節點」
✅ 最後一張可設計明確的 CTA
```

輪播本質上是一個**精簡的銷售流程**，在滑動過程中完成心理轉變。

---

## 高轉換輪播的心理路徑

```
第 1–2 張：現況共鳴
  → 說出讀者正在經歷的狀況或痛點
  → 讓他心想「這說的就是我」

第 3–4 張：問題放大
  → 揭示這個問題的根本原因
  → 說明「你之前的做法為什麼沒效」

第 5–6 張：新觀點/方法
  → 提出你的框架或解決方案
  → 建立「原來可以這樣」的認知轉變

最後一張：行動呼召（CTA）
  → 清楚告訴讀者下一步要做什麼
  → 留言關鍵字 / 連結 bio / 私訊我
```

> 關鍵：每一張都要讓讀者有理由「再滑一張」。

---

## 多數創作者的問題

```
❌ 只輸出零散資訊（tip list）
   → 有知識感，但缺乏引導決策的設計
   → 內容看完沒有後續

❌ 沒有設計「心理轉變」
   → 讀者看完還是不知道為什麼要找你
   → 沒有建立信任，無法轉換
```

## 設計原則

### 封面（第 1 張）
```
目標：讓人停下來點開
✅ 一個清晰的主張或問題（非「5 個技巧」清單）
✅ 與目標受眾的痛點直接對話
✅ 視覺乾淨，文字少於 10 個字
```

### 中間張（第 2–N 張）
```
目標：建立信任，製造「想繼續看」的動力
✅ 每張只有一個核心訊息
✅ 用對話感的語氣，不用說教語氣
✅ 可以用數據、對比、例子強化說服力
✅ 結尾留「懸念」讓人繼續滑
```

### 最後一張（CTA 張）
```
目標：把信任轉化為行動
✅ 明確的單一行動（不要多於一個 CTA）
✅ 留言關鍵字觸發 DM（最高互動率）
✅ 或引導到 bio 連結（進入漏斗）
```

## 輪播在 LIFE 系統中的位置

在 [[LIFE根系內容系統]] 中，輪播承擔 **I（Influence 影響力觸點）** 的角色：

```
長根內容（L）：深度長文、完整指南
    ↓ 拆解
輪播（I）：視覺化重點摘要 → 建立信任
    ↓ 轉化
漏斗（F）：留言 → DM → Email 序列
    ↓ 留存
付費社群（E）：Skool 會員
```

一篇長根內容通常可以拆出 2–3 組不同角度的輪播。

---

## 短影音 vs 輪播 使用時機

| | 短影音（Reels）| 輪播（Carousel）|
|-|--------------|----------------|
| 主要目標 | 觸及陌生人、漲粉 | 深化信任、轉換 |
| 適合內容 | 娛樂感、趨勢、Hook | 教學、框架、觀點 |
| 演算法 | 推薦給非粉絲 | 主要推給既有粉絲 |
| 轉換效率 | 低（看完即走）| 高（主動投入）|
| 製作時間 | 高（剪輯）| 中（設計）|

**策略**：Reels 負責觸及新受眾，輪播負責轉換既有受眾。
