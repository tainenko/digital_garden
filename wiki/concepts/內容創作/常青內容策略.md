# 常青內容策略

製作能在搜尋引擎長期排名、持續帶來流量的影片，而非追逐短期熱點。

## 定義

**常青內容（Evergreen Content）**：解決永久存在的問題、回答持續被搜尋的問題的內容。

對比：
- 常青：「如何在30天內學會吉他」
- 熱點：「回應 [某熱門話題] 的看法」

## 為什麼常青更有價值

| 熱點內容 | 常青內容 |
|---------|---------|
| 1週後沒人看 | 3年後還在被搜尋 |
| 需要持續生產 | 一次投資，長期報酬 |
| 演算法依賴高 | SEO 驅動，被動流量 |
| 品牌定位模糊 | 建立特定領域專家形象 |

## 常青選題公式

Ali 常用格式：
- **「如何在 X 天內做到 Y」** — 承諾清晰結果
- **「2026 年最佳 X 指南」** — 搭配年份保持時效感
- **「初學者 X 完整攻略」** — 覆蓋搜尋量最大的入門關鍵字

## 選題評估標準

1. **搜尋量**：這個問題有多少人在找答案？
2. **競爭度**：現有影片品質如何？有沒有切入空間？
3. **持久性**：3年後這個問題還會被問嗎？
4. **相關性**：符合你的[[利基優先策略]]嗎？

## 與 SEO 的關係

YouTube 是全球第二大搜尋引擎。常青內容的 SEO 邏輯：
- 標題包含搜尋關鍵字
- 縮圖清楚傳達影片解決什麼問題
- 前30秒確認觀眾「找對了」（降低跳出率）
