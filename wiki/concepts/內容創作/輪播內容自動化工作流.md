# 輪播內容自動化工作流

## 概覽

使用 **Claude Code + Higgsfield MCP** 打造 IG 輪播內容自動化流水線。

```
一句主題輸入
    ↓
Claude Code（策略 + 文案 + 流程控制）
    ↓ MCP 呼叫
Higgsfield（視覺生成）
    ↓
完整輪播素材輸出
```

來源：Chase AI YouTube 教學（"Claude Code + Higgsfield MCP = Content MACHINE"）
實際使用者：[[growithfyn]]（在其 IG reel 中展示此工作流成果）

---

## 工具角色分工

| 工具 | 角色 | 負責內容 |
|------|------|---------|
| **Claude Code** | 大腦／導演 | 內容策略、文案撰寫、流程控制、呼叫 MCP |
| **Higgsfield MCP** | 視覺製作 | 圖像生成、風格控制、批量輸出 |
| **CLAUDE.md** | 記憶體 | 品牌語調、受眾定義、POV、設計規範 |

---

## 前置設定

### 1. 安裝 Higgsfield MCP Server

```bash
# 在 Claude Code settings.json 加入 MCP server
{
  "mcpServers": {
    "higgsfield": {
      "command": "npx",
      "args": ["-y", "@higgsfield/mcp-server"],
      "env": {
        "HIGGSFIELD_API_KEY": "your_api_key"
      }
    }
  }
}
```

### 2. CLAUDE.md 設定品牌規範

```markdown
## 品牌設定
- 目標受眾：[描述你的 ICP]
- 核心 POV：[你的獨特觀點]
- 語調：[親切/專業/直白...]
- 視覺風格：[簡約/深色/奶油色...]
- 輪播格式：10 張，第 1 張封面 + 8 張內容 + 1 張 CTA
```

---

## 完整工作流程

### 步驟一：輸入根系主題

```
對 Claude Code 說：
「根據我的品牌設定，針對『[主題]』
 幫我製作一組 10 張的 IG 輪播貼文」
```

### 步驟二：Claude Code 產出文案結構

```
Claude 自動完成：
1. 封面文案（Hook）
2. 第 2–3 張：現況共鳴（讀者痛點）
3. 第 4–5 張：問題放大（為什麼現在的做法沒效）
4. 第 6–8 張：解決方案（你的框架／方法）
5. 第 9 張：結果預覽（社會證明或數據）
6. 第 10 張：CTA（留言關鍵字）
```

### 步驟三：呼叫 Higgsfield MCP 生成視覺

```
Claude Code 自動呼叫 Higgsfield，為每一張產生：
- 背景圖像（符合品牌調性）
- 文字配置建議
- 色彩方案
→ 輸出：10 張對應的圖像素材
```

### 步驟四：組合輸出

```
Claude Code 整合文案 + 圖像，產出：
- 每張的完整說明（文字 + 圖片路徑）
- 發布用的完整貼文說明（Caption）
- 留言漏斗關鍵字設定
```

## 注意事項

```
⚠️ 品牌一致性：CLAUDE.md 的視覺規範要夠具體，
   否則 Higgsfield 生成的風格會不一致

⚠️ 人工審核：AI 生成的文案仍需確認是否符合
   你的真實 POV 和第一手經驗（Google E-E-A-T 要求）

⚠️ CTA 設計：最後一張的留言關鍵字要搭配
   ManyChat 或 IG 自動回覆工具才能形成完整漏斗
```
