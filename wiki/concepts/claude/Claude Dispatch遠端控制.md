# Claude Dispatch 遠端控制

## 什麼是 Claude Dispatch

[[Anthropic]] 於 **2026 年 3 月 18 日**正式推出 Claude Cowork Dispatch。讓使用者透過手機發出指令，桌電上的 Claude 在背景執行任務，完成後回傳結果。

手機是遙控器，桌電才是真正在做事的地方。

## 運作原理

1. 用手機開啟 Claude（claude.ai 或 App）
2. 發出任務指令
3. 桌電上的 Claude Cowork 接收指令，在背景執行
4. 完成後推播通知到手機，可查看結果

## 五個上班族實用場景

1. **通勤中整理報告**：在捷運上說「把桌面的週報草稿潤稿後存成 PDF」，到公司就能印
2. **開會前準備資料**：會議途中發指令「把 Google Drive 的 Q2 數字整理成表格」
3. **下班後繼續跑任務**：離開辦公室後，讓桌電繼續跑批量作業
4. **跨時區協作**：睡前發指令，起床看結果
5. **緊急任務遠端觸發**：不在電腦前也能啟動耗時任務

## Dispatch vs Computer Use vs Remote Control

| 面向 | Dispatch | Computer Use（Claude Code CLI）| 一般遠端桌面 |
|------|----------|-------------------------------|------------|
| 控制方式 | 自然語言 | 自然語言（CLI）| 滑鼠鍵盤完整控制 |
| 執行環境 | 本機 Cowork | 本機 Claude Code | 本機整台電腦 |
| 適合對象 | 非技術用戶 | 開發者 | 任何人 |
| 任務類型 | 文件、資料整理 | 程式開發、系統操作 | 任何桌面任務 |
