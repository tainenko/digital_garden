# Claude for Chrome 完整教學

## 什麼是 Claude for Chrome

[[Anthropic]] 推出的 Chrome 擴充功能，讓 Claude 直接在瀏覽器側邊欄讀取頁面、點擊按鈕、填寫表單，把重複的網頁操作變成一句話的事。

## 五大使用場景

1. **網頁閱讀摘要**：開啟任何頁面，讓 Claude 即時總結重點
2. **表單自動填寫**：描述要填什麼，Claude 直接幫你點欄位輸入
3. **資料整理**：從多個頁面抓取資料，整理成表格或報告
4. **Gmail 整合**：讀信、分類、草擬回覆（需開啟 Gmail Connector）
5. **操作指引**：不熟悉的網站，讓 Claude 導引你點哪裡

## Claude for Chrome vs Gemini in Chrome

| 面向 | Claude for Chrome | Gemini in Chrome |
|------|------------------|-----------------|
| 費用 | 需 Claude 付費方案 | 免費（Google 帳號即可）|
| 核心強項 | 直接點按鈕、填表單（代理操作） | Skills 功能、一鍵重用 Prompt |
| 設計邏輯 | 行動導向（幫你「做」） | 對話導向（幫你「想」）|
| 跨站整合 | 搭配 Connectors（Gmail、Adobe…） | 與 Google 服務深度整合 |
| 適合對象 | 需要 AI 替你執行操作的人 | 日常搜尋增強、Google 用戶 |

## 安全原則

- Claude 只讀取你當下開啟的頁面
- 不會在背景偷偷瀏覽其他分頁
- 表單提交等不可逆操作會先確認

## 與 Cowork 的差異

- **Claude for Chrome**：操作瀏覽器內的網頁
- **[[CoWork桌面工具指南|Claude Cowork]]**：操作整個桌面（本機檔案、任何應用程式）
