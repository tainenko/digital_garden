# 證據能力（Evidence Admissibility）

## 定義
證據能力是指某項證據**得以提交法庭調查、用於認定犯罪事實的資格**。

依司法院釋字第582號，具備證據能力須同時滿足三要件：
1. 與[[待證事實]]具**自然關聯性**
2. 依**法定程序**取得
3. **未受法律禁止或排除**

## 與[[證明力]]的層次關係

```
第一層：證據能力（有沒有資格進法庭？）
    ↓ 有能力才進入下一層
第二層：證明力（進了法庭後說服力有多強？）
    ↓ 達到積極證據標準
第三層：有罪 / 無罪認定
```

先無能力，後談不上證明力。

## 絕對排除（7類，無任何例外）

| 類型 | 說明 | 法律依據 |
|------|------|---------|
| 非法取供 | 刑求、疲勞訊問取得的口供與證詞 | 刑訴法第156條 |
| 未具結證詞 | 證人/鑑定人未依程序具結 | 刑訴法第158條之3 |
| 組織犯罪庭外陳述 | 未在檢察官/法官前所為陳述 | 組織犯罪防制條例 |
| 非法通訊監察 | 違反通訊保障及監察法之監聽 | 通保法 |
| 違法接見錄製 | 監獄人員非法錄製律師接見 | 刑訴法 |
| 協商陳述 | 未成立協商判決時的先前協商陳述 | 刑訴法第455條之7 |
| 陷害教唆 | 對無犯罪故意者施以引誘所得證據 | 最高法院判例 |

## 相對排除（6類，可能有例外）

| 類型 | 原則 | 例外條件 |
|------|------|---------|
| 夜間詢問口供 | 無能力 | 例外情況（緊急等） |
| 證人個人意見或推測 | 無能力 | 與事實相關且有助判斷時 |
| **傳聞證據** | 無能力 | 法定例外（不能到庭等情形） |
| 未告知權利口供 | 無能力 | 例外認定 |
| 另案監聽內容 | 無能力 | 符合通保法許可情形 |
| 違法取得但符合均衡原則 | 無能力 | 刑訴法第158條之4：人權保障 vs. 公共利益均衡 |

## 傳聞法則（Hearsay Rule）
庭外陳述（非在法庭上親自陳述）原則上不具證據能力，理由：
- 無法對陳述人進行交互詰問
- 無法確認陳述人的感知、記憶與表達是否可信

**例外**（法院依職權認定）：陳述人死亡、失蹤、無法到庭，且原陳述具特信性時，得例外承認證據能力。

## 法律依據
- 刑事訴訟法第 155 條第 2 項
- 刑事訴訟法第 158 條之 4（違法取得均衡原則）
- 司法院釋字第 582 號
