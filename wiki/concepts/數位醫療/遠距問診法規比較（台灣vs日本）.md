# 遠距問診法規比較（台灣 vs 日本）

台灣與日本都採「例外許可制」——醫師親自看診為原則，遠距為例外，但開放程度與進展速度有所不同。

---

## 台灣

### 法源
- **醫師法第 11 條**：醫師須親自看診；但第 2 項授權例外
- **通訊診察治療辦法**：2018 年訂定，2024 年 1 月最新修正

### 合法適用情境（2024 年修正後）

| 情境 | 說明 |
|------|------|
| 慢性病長期用藥 | 病情穩定的**複診**患者 |
| 急性後期照護 | 出院後追蹤 |
| 居家醫療照顧 | 行動不便、偏鄉患者 |
| 長照機構照顧 | 住民定期追蹤 |
| 疾病末期照顧 | 安寧療護 |
| 特殊疫情期間 | 如 COVID-19 擴大條款 |

### 核心限制
- **初診原則不可遠距**（須先有實體就診紀錄）
- 遠距問診機構須向衛福部申請指定
- 2024 年修正新增：可開立電子處方箋、擴大慢性病長期用藥範圍

### 對業者的影響
- [[Health2Sync 智抗糖]]：走**慢性病複診**通路，合規
- [[IC Care]]：定位在「諮詢」而非「問診」，刻意迴避法規紅線
- [[AlleyPin 翔評互動]]：診所管理 SaaS，不涉及問診，無風險

## 日本

### 法源
- **医師法第 20 条**：醫師須直接診察（対面原則）
- **厚生労働省「オンライン診療の適切な実施に関する指針」**：最新版 2022 年修訂

### 開放歷程

| 時間 | 事件 |
|------|------|
| 2018 | 厚勞省正式允許遠距複診（慢性病、再診） |
| 2020/04 | COVID-19 特例：**初診也可遠距**（時限性） |
| 2022/01 | 指針修訂：初診遠距須為「かかりつけ医（家庭醫師）」執行 |
| 2024 | 診療報酬改定：慢性病遠距診療加算擴充 |
| 2025/12 | 醫療法修正公布：**オンライン診療正式寫入醫療法**，醫療機構須向都道府縣申報 |

### 普及率（2024）
- 對應遠距問診的醫療機構：約 12,507 家（全體約 16%）

### 核心限制
- 初診原則仍須對面（家庭醫師例外）
- 高齡者數位落差是最大障礙
- 醫師端意願低（報酬偏低、法律責任疑慮）

### LINE Doctor 案例
[[LINE Healthcare]] 的 LINE Doctor 於 2025 年 6 月關閉——即使背靠 LINE 月活 9,500 萬用戶，日本遠距問診商業化仍困難，印證上述結構性障礙。

---

## 台灣 vs 日本 對比

| 面向 | 台灣 | 日本 |
|------|------|------|
| 法規名稱 | 通訊診察治療辦法 | オンライン診療指針 + 醫療法 |
| 初診遠距 | ❌ 原則不可 | ❌ 原則不可（家庭醫師例外） |
| 慢性病複診 | ✅ 合法 | ✅ 合法 |
| 電子處方箋 | ✅（2024 年修正新增） | ✅ |
| 醫療機構門檻 | 須向衛福部申請指定 | 須向都道府縣申報（2025 法制化） |
| 普及障礙 | 醫師培訓、基礎建設 | 高齡化數位落差、醫師意願、報酬偏低 |
| 進展速度 | 中等（疫情後持續推進） | 較慢（醫界保守、法制化晚）|

---

## 對數位醫療新創的啟示

1. **慢性病複診是合規路徑**：台日兩地都允許，Health2Sync 的模式在兩地都走得通
2. **「諮詢」≠「問診」**：IC Care 的定位選擇是刻意的法規套利
3. **日本比台灣更難進入**：制度更保守、醫師意願更低，LINE Doctor 關閉是警示
4. **法制化是趨勢**：日本 2025 年將遠距問診正式寫入醫療法，預期監管會更嚴格但也更明確，反而有利長期合規業者
