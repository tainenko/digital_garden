# 訓練資料策略（LoRA）

針對二次元角色 LoRA 訓練的資料收集、篩選與品質控制策略。

---

## 資料來源比較

### 方案 A：Danbooru 直接下載
```
搜尋條件：
tachibana_arisu solo height:>=1024 width:>=1024 -monochrome -comic
工具：imgbrd-grabber 批次下載
```

| 優點 | 缺點 |
|------|------|
| 快速、免費、量大 | 多畫師 → 畫風不統一 |
| 標籤豐富 | 角色外觀細節各圖不一致 |
| 多角度、多場景 | 可能包含低品質圖片 |

**適合**：第一輪快速驗證，確認方向可行性。

### 方案 B：[[Nano Banana Pro]] 合成資料
使用 AI 工具生成「角色設定圖」：
- 統一畫風、統一外觀
- 覆蓋多角度（正面/側面/背面）、多表情、多動作
- 建議數量：14–15 張

| 優點 | 缺點 |
|------|------|
| 畫風統一、角色一致性高 | 需額外生成步驟 |
| 可控角度與表情 | 多樣性相對有限 |
| 降低 concept bleeding 風險 | |

**適合**：正式訓練、追求高一致性的角色 LoRA。

---

## 資料篩選標準

| 條件 | 要求 |
|------|------|
| 人數 | Solo（單人） |
| 解析度 | 1024px 以上 |
| 色彩 | 彩色（排除 monochrome） |
| 格式 | 非漫畫格（排除 comic） |
| 服裝 | 統一服裝（至少初訓階段） |
| 角度 | 多角度（正/側/背/斜） |
| 文字 | 無文字覆蓋 |

---

## 資料量建議

| 階段 | 建議量 | 說明 |
|------|--------|------|
| 初次驗證 | 10–15 張 | 快速確認方向 |
| 正式訓練 | 14–15 張（合成） | 品質優先於數量 |

> 結論：**品質 > 數量**。15 張統一畫風的圖遠好過 50 張多畫師的圖。

---

## 資料標籤流程

配合 [[Feature Disentanglement]] 策略對每張圖進行三層標籤：
1. 外觀標籤（每張必填）
2. 服裝標籤（依實際服裝）
3. 情境標籤（動作、場景）
