# 待證事實（Facts Requiring Proof）

## 定義
在刑事訴訟中，須以[[積極證據]]予以證明的事實，稱為「待證事實」。並非法庭上的所有主張都需要舉證——有些事實屬「免證事實」，毋庸舉證。

## 需要證明的8類事實

| 類型 | 例示 |
|------|------|
| 1. 犯罪構成要件事實 | 行為、故意/過失、因果關係 |
| 2. 共犯/正犯身分 | 是否為共謀共同正犯、教唆犯 |
| 3. 阻卻違法/責任事由 | 正當防衛（刑法23條）、精神障礙（刑法19條） |
| 4. 加重/減輕情節 | 累犯（刑法47條）、自首（刑法62條） |
| 5. 量刑基準金額 | 幣值犯罪、走私犯罪的金額 |
| 6. 處罰條件 | 特別法規定的前置要件 |
| 7. 量刑審酌事項 | 刑法第57–59條十款審酌事由（適用[[嚴格證明與自由證明|自由證明]]） |
| 8. 程序事實 | 先前判決、被告死亡、告訴乃論之告訴 |

## 免證事實（無需舉證）

| 類型 | 法律依據 | 例示 |
|------|---------|------|
| 眾所週知事實 | 刑訴法第 157 條 | 曆法、星期幾、重大歷史事件 |
| 法院職務已知事實 | 刑訴法第 158 條 | 法官在同一案件中已知悉的事實 |

## 與舉證責任的關係
- [[無罪推定原則]]：待證事實的舉證責任在於**檢察官/告訴人**，被告無須自證清白。
- 被告對阻卻違法事由（如正當防衛）**提出合理懷疑**即可，毋需積極證明。
- 待證事實是否以[[嚴格證明與自由證明|嚴格或自由證明]]處理，取決於事實性質（→ 第六篇）。

## 法律依據
- 刑事訴訟法第 154 條第 2 項：「犯罪事實應依證據認定之，無證據不得認定犯罪事實」
- 刑事訴訟法第 157、158 條：免證事實規定
