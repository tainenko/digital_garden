# Email 行銷與電子報

## 定義

EDM（Electronic Direct Mail）= 以電子郵件為載體，向名單訂閱者傳遞品牌訊息、促銷活動或內容，達成**留存、轉換、升單**目標的行銷手段。

> Email 行銷平均 ROI 為 1:36——每投入 1 元，可回收 36 元。遠高於社群廣告。

---

## 核心指標

| 指標 | 說明 | 健康標準 |
|------|------|---------|
| **開信率（Open Rate）** | 打開郵件人數 / 發送人數 | 電商 20–25%，B2B 25–35% |
| **點擊率（CTR）** | 點擊連結人數 / 發送人數 | 2–5% |
| **點擊開信率（CTOR）** | 點擊 / 開信人數 | 更真實反映內容吸引力，目標 > 20% |
| **退訂率** | 退訂人數 / 發送人數 | < 0.5% 為健康 |
| **垃圾信率** | 被標為垃圾 / 發送人數 | < 0.1%（Google/Yahoo 新規硬性要求）|
| **轉換率** | 完成目標動作 / 發送人數 | 依目標不同，通常 1–3% |

## 名單建立策略

### 線上渠道
```
官網彈出視窗（Exit-intent popup）
內容升級（Lead Magnet）：免費電子書、模板、折扣碼
結帳流程中勾選訂閱
社群媒體導流（IG bio 連結、限時動態 CTA）
```

### 線下渠道
```
實體門市填單 / 掃 QR Code
活動現場換取訂閱（名片掃描、報名表）
客服電話確認後徵詢同意
```

### 廣告獲取
```
Meta Lead Ads → 直接在 Facebook/IG 填表，無需跳轉頁面
Google Ads → 落地頁搭配訂閱表單
```

> **重要**：台灣《個人資料保護法》要求明確告知蒐集目的，並取得同意，不可直接購買名單。

## Google / Yahoo 2024 新規（必須遵守）

2024 年 2 月起，每月發送 5,000+ 封的寄件者必須符合：

```
1. 驗證機制（三選一，建議全部設定）
   → SPF：指定合法發信 IP
   → DKIM：數位簽章驗證寄件者
   → DMARC：定義驗證失敗時的處理政策

2. 垃圾信率 < 0.10%（超過 0.30% 會被封鎖）

3. 一鍵退訂（RFC 8058 List-Unsubscribe-Post header）
   → 用戶點退訂後，48 小時內必須處理完成
```

## 郵件類型

| 類型 | 說明 | 範例 |
|------|------|------|
| **歡迎序列** | 新訂閱者自動觸發，3–5 封 | 品牌故事 → 熱門商品 → 首購優惠 |
| **促銷型 EDM** | 特定活動或折扣 | 雙 11 倒數、週年慶 |
| **內容型電子報** | 定期知識、趨勢分享 | 每週行銷案例、產業週報 |
| **棄購挽回** | 加入購物車未結帳，自動觸發 | 「您的商品還在等您」 |
| **再啟動（Win-back）** | 180 天未開信者，再次接觸 | 「好久不見，這是給你的優惠」 |
| **生命週期觸發** | 生日、周年、里程碑 | 會員生日專屬折扣 |

## 主旨行（Subject Line）最佳實踐

```
黃金公式：[好奇/痛點/利益] + 數字或具體性 + 緊迫感

✅ 好範例：
「3 個讓開信率翻倍的方法（大多數人都不知道）」
「【限時 24 小時】會員專屬 85 折優惠」
「你的購物車快過期了 🛒」

❌ 避免：
過多大寫、驚嘆號（觸發垃圾信過濾）
「免費」、「賺錢」等觸發詞
主旨超過 50 字元（手機顯示截斷）
```

## 行銷自動化（Marketing Automation）

```
觸發條件（Trigger）→ 等待條件（Delay）→ 動作（Action）→ 分支（Branch）

範例：歡迎序列
Day 0：訂閱 → 發送「歡迎信 + 10% 折扣碼」
Day 3：[分支] 開信？→ 是：發送「品牌故事」/ 否：改主旨重發一次
Day 7：[分支] 有購買？→ 是：加入 VIP 名單 / 否：發送「首購障礙排除」
Day 14：未購買者 → 發送「社群證明（評論截圖）」
```

## Email + SMS 整合策略

```
Email → 深度內容、促銷細節（PC 轉換高）
SMS / LINE → 即時通知、限時提醒（手機即時性高）

組合使用：
→ Email 發送完整促銷說明（提前 3 天）
→ 活動當天 LINE 推播倒數提醒
→ 棄購後 1 小時 SMS 簡短提醒
```
