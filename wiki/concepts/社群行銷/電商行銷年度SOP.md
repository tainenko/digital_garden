# 電商行銷年度 SOP

## 年度節奏：三層活動結構

```
第一層：大型促銷節點（全力衝刺，3 個月前備料）
  → 雙 11（11/11）、雙 12（12/12）、年中慶（6 月）、週年慶

第二層：季節性節點（提前 6 週規劃）
  → 情人節、母親節、父親節、中秋、春節

第三層：品牌自訂節點（填補空窗期）
  → 品牌週年、新品上市、季節換倉清庫存
```

**原則**：活動之間保持 2–3 週的「緩衝期」，避免用戶活動疲勞、退訂率飆升。

## 促銷機制設計

### 常見促銷類型

| 機制 | 適用情境 | 優點 | 缺點 |
|------|---------|------|------|
| **滿額折扣**（滿 X 折 Y）| 提升客單價 | 直覺好理解 | 容易被套利 |
| **買 X 送 Y**（BOGO）| 出清庫存 | 感知價值高 | 毛利壓縮 |
| **限時閃購**（倒數計時）| 衝刺轉換 | 製造緊迫感 | 過度使用會麻木 |
| **會員專屬價** | 提升會員黏著 | 差異化獎勵 | 需要會員系統支援 |
| **組合包（Bundle）** | 提升平均訂單金額 | 降低比價 | 庫存管理複雜 |

### 滿額門檻設計技巧
```
計算平均客單價 → 設門檻在客單價的 1.2–1.5 倍
例：平均客單 NT$ 800 → 設「滿 1,000 折 100」
讓大多數人「再加一點就達標」，自然升單
```

## 文案撰寫公式

### 促銷文案四要素
```
1. 驚喜感（Surprise）
   → 「這是我們做過最大的折扣」

2. 稀缺性（Scarcity）
   → 「限量 100 組」「僅剩最後 3 天」

3. 行動呼召（CTA）
   → 清楚說明「現在就去」「立即領取」

4. 會員身份強調
   → 「專屬會員限定」「你是我們的 VIP，所以提前告訴你」
```

### 模板範例
```
主旨：【會員限定】你的雙 11 提前購特權（僅限今天）

內文：
[驚喜] 今年雙 11，我們決定給會員一個不一樣的禮物——
提前 3 天開放專屬折扣，搶在一般人之前。

[稀缺] 限量 200 組組合包，賣完就回原價。
上次活動，不到 6 小時就售罄了。

[CTA] 立即搶購 →（按鈕）

[身份] 這封信只寄給我們的會員，謝謝你一直以來的支持。
```

## LINE 官方帳號推播策略

### 發送頻率
```
平時（非活動期）：每週 1–2 則
活動衝刺期：每天 1 則（最多不超過 2 則）
活動結束後：立刻恢復平時頻率（避免過後繼續轟炸）
```

### 內容比例建議
```
40% 教育型 / 娛樂型（不推銷，建立信任）
40% 促銷型（折扣、新品、活動）
20% 互動型（投票、問答、抽獎）
```

### 推播時間
```
電商最佳時段：
→ 平日：11:30–13:00（午休）、19:00–21:00（下班後）
→ 週末：10:00–12:00

避免：早上 7 點前、深夜 11 點後（容易被封鎖）
```

## 會員經營四階段

```
第一階段：招募（Recruit）
  → 首購優惠、社群廣告導流、KOL 帶動訂閱

第二階段：活化（Activate）
  → 歡迎序列 Email（3–5 封）、完整填寫個人資料獎勵

第三階段：分層（Tier）
  → 依消費金額或次數區分：一般 / 銀級 / 金級 / VIP
  → 不同等級享有不同權益（折扣、提早開賣、免運門檻）

第四階段：回購（Repurchase）
  → 補貨提醒（依購買品項預估消耗週期）
  → 沉睡名單喚醒（180 天未購買 → Win-back 活動）
  → 生日/周年禮（個人化驚喜）
```

## 數位互動增強參與度

| 工具 | 目的 | 範例 |
|------|------|------|
| 遊戲化（轉盤/刮刮卡）| 增加互動、引流 | LINE 官帳抽獎活動 |
| 直播帶貨 | 即時互動、衝刺轉換 | 新品上市直播首賣 |
| O2O（線上到線下）| 到店取貨、門市體驗 | 線上訂購，到門市領取加碼贈品 |
| UGC 徵稿 | 素材蒐集、社群聲量 | 「曬單贈積分」活動 |

## 活動覆盤檢查清單

```
□ 整體 GMV vs 目標達成率
□ 新客 / 舊客比例（>50% 舊客表示品牌黏著度健康）
□ 活動期間退訂率 / 封鎖率是否上升
□ 哪個促銷機制轉換率最高
□ 哪個 Email 主旨開信率最高
□ 庫存是否提前售罄（需補貨預警機制）
□ 下次同活動的改善方向（立刻記錄，趁記憶猶新）
```
