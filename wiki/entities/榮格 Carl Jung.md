# 榮格 Carl Gustav Jung（1875–1961）

## 基本資訊

- **全名**：Carl Gustav Jung
- **國籍**：瑞士
- **身分**：精神科醫師、心理學家
- **學派**：分析心理學（Analytical Psychology）創始人
- **師承**：曾為 Sigmund Freud 弟子，後因理論分歧分道揚鑣（約 1912 年）

## 核心理論貢獻

| 概念 | 年份 | 說明 |
|------|------|------|
| 分析心理學 | 1912 | 與佛洛伊德精神分析的分支，強調集體潛意識 |
| 集體潛意識（Collective Unconscious） | 1916 | 人類共享的深層心理層次，含原型意象 |
| 原型（Archetype） | 1919+ | 集體潛意識中的普遍模式（陰影/阿尼瑪/阿尼姆斯/自性）|
| 陰影（Shadow） | 1917 | 人格中被壓抑、否認的部分；同性投射對象 |
| 人格面具（Persona） | 1920s | 社會角色扮演的面具；與陰影互補 |
| 個體化歷程（Individuation） | 1921 | 整合人格各部分、成為完整自我的終身歷程 |
| 心理類型（MBTI 前身） | 1921 | 內向/外向 + 四種功能（思考/情感/感覺/直覺）|

## 心靈四層結構

```
Self（自性）— 全體心靈的中心
  ├── Ego（自我）— 意識的核心
  ├── Persona（人格面具）— 社會呈現
  └── Shadow（陰影）— 被壓抑的對立面
```
