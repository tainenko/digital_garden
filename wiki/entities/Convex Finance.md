# Convex Finance

## 概述

Convex 是建立在 [[Curve Finance]] 之上的**收益聚合協議**，讓普通用戶無需自行鎖倉 CRV 即可享受最優化的 Curve LP 報酬。

## 核心價值

- 聚合了大量用戶的 CRV，統一鎖倉為 veCRV，獲得最大 Gauge 投票權
- 用戶只需存入 Curve LP Token → 自動領取 CRV + CVX + 手續費
- 消除了個人鎖倉 CRV（最長 4 年）的流動性犧牲

## CVX Token

- Convex 平台治理代幣
- 可鎖倉（vlCVX）獲得 Curve Gauge 投票權的代理控制
- 是 [[Curve-Convex收益策略]] 收益的第三層來源

## Bribe 機制中的角色

Convex 控制 Curve 大量投票權，協議可通過 Votium 等平台「賄賂」vlCVX 持有者將票投給指定池子。這使得 Convex 成為 DeFi 流動性導向的**關鍵基礎設施層**。
