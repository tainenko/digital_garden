# Boot.dev

## 基本資料

- **類型**: 後端開發學習平台（互動式課程訂閱 + 免費 YouTube 內容）
- **網站**: https://www.boot.dev
- **定位**: 以遊戲化、互動式練習方式學習後端工程技能；課程含自動評分題目

## 訂閱方案

- 付費年訂閱，優惠碼 `PRIME` 或 `TEEJ` 可享 25% 折扣
- 課程包含 SQL、Python、Go、HTTP、Algorithms 等後端核心技能
