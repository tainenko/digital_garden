# Anthropic Academy

**Anthropic 官方免費線上學習平台**，提供從 AI 素養到進階 Agent 開發的完整課程體系。

- **網址**：academy.anthropic.com
- **費用**：全部免費（需註冊帳戶）
- **語言**：英文
- **課程數**：13 堂（截至 2026 年）

---

## 課程體系

課程分三大類，詳見 [[Anthropic Academy 13堂課程完整指南]]：

1. **開發技術實戰**（8 堂）：從 Claude 101 到 API 開發、MCP、Cloud 平台整合
2. **AI 素養**（2 堂）：4D 框架、提示詞設計
3. **教育應用**（3 堂）：針對教師、學生、非營利組織
