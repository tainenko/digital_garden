# Skillsmap

## 基本資訊

- **類型**：Claude Skills 第三方市場平台
- **定位**：一站式 Claude Skills 搜尋、安裝平台
- **技能數量**：10,000+ 現成 Skills

## 核心功能

- **智能搜索**：依需求搜尋現成 Skills，不用自己從零寫
- **一鍵安裝**：直接把 Skill 安裝進 Claude，即用
- **分類瀏覽**：按職業、工具、用途分類

## 定位

對比自己撰寫 [[Claude Code Plugins插件系統|Claude Skills]]：Skillsmap 讓使用者跳過設計步驟，直接套用社群貢獻的工作流。適合不想花時間自建、或想參考現有範本再改的使用者。
