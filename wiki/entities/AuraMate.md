# AuraMate

AI-powered Chinese metaphysics platform; developer of the **灵伴** (Spirit Companion) Bazi application and the [[BaziQA-Benchmark]].

## Key Facts
- Affiliated with research from **Shanghai Jiao Tong University**
- Published arXiv:2602.12889 — *BaziQA-Benchmark: Evaluating Symbolic and Temporally Compositional Reasoning in LLMs*
- Open-sourced full dataset and evaluation code (GitHub: chenjiangxi/baziqa, MIT license)

## Products & Research
- **灵伴 (AuraMate app)**: Bazi interpretation service; scored 42.0% on BaziQA Contest8 in 2025; five-year average 37.5%
- **Structured Reasoning Protocol (SRP)**: Three-step proprietary methodology — pattern assessment → force prioritization → event inference — yielding +3 to +30 pp accuracy gains over baseline LLMs
- **Custom chart calculation engine**: Converts birth date/time to Four Pillars (四柱) representation for LLM input
