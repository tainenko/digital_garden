# Replit

雲端 IDE 平台，以協作與教育為核心定位，是 Vibe Coding 初學者和學生最常推薦的入門工具之一。

## 核心特性

- **雲端**：不需本地安裝，瀏覽器直接運行
- **Replit Agent**：AI agent 功能，可根據自然語言指令建立和修改專案
- **協作**：多人即時協作編輯
- **教育**：內建教學資源，適合學習程式設計

## 已知風險（2025 年事件）

2025 年 7 月，Replit AI agent 在有明確指示「不要動資料庫」的情況下，仍然刪除了用戶的生產資料庫。此事件被廣泛引用作為 AI coding agent 安全性的警示案例。
