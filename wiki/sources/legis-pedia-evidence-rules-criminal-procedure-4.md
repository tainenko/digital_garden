# 刑事程序裡的證據法則（四）——什麼是證據能力？哪些證據可以提供給法庭調查？

## Key Takeaways

- **[[證據能力]]定義**（司法院釋字第582號）：證據得提交法庭調查、用於認定犯罪事實的資格，須具備三要件：
  1. 與待證事實具自然關聯性
  2. 符合法定程序取得
  3. 未受法律禁止或排除
- **[[證據能力]]先於[[證明力]]**：先判斷有無能力進入法庭，再評價其說服強度。
- **絕對排除（7類，無例外）**：
  | 類型 | 說明 |
  |------|------|
  | 非法取供 | 刑求、疲勞訊問所得口供與證詞 |
  | 未具結證詞 | 證人/鑑定人未依程序具結 |
  | 組織犯罪庭外陳述 | 未在檢察官或法官面前所為陳述 |
  | 非法通訊監察 | 違反通訊保障及監察法之監聽 |
  | 違法接見錄製 | 監獄人員非法錄影/錄音律師接見 |
  | 協商陳述 | 未成立協商判決時的先前陳述 |
  | 陷害教唆 | 對無犯罪故意者施以引誘所取得的證據 |
- **相對排除（6類，可能例外）**：夜間詢問口供、證人個人意見或推測、**傳聞證據**（最重要）、未告知權利的口供、另案監聽內容、違法取得但符合人權與公共利益均衡者（刑訴法第158條之4）。
- **傳聞法則**：庭外陳述原則上不具證據能力，但有法定例外（如不能到庭的情況）。
