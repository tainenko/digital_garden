# Cursor AI 全攻略：Vibe Coding 教學（夏木樂）

## Origin
- **URL**: https://simular.co/blog/post/cursor-ai-vibe-coding
- **語言**: 繁體中文
- **性質**: 操作教學

## Key Takeaways

- Cursor 以 VS Code 為底層架構，是 Vibe Coding 最主流的 IDE 工具
- 核心操作：Cmd+I 開啟 AI 對話面板，輸入自然語言指令即可執行多檔案修改
- **七步操作流程**：安裝設定 → 初始化專案 → 核心開發 → 迭代優化 → 視覺設計 → 除錯 → 部署
- 可直接上傳截圖/設計稿，AI 自動分析視覺需求並生成對應 UI
- 除錯方式：直接貼 error message 進對話框，AI 自動分析 stack trace 並修復
- Cmd+K 可在原地開啟 local 對話視窗做小幅修改（含 diff 預覽）
- **關鍵技巧**：複雜需求拆小步、新階段開新對話（避免舊 context 干擾）、手動選擇相關檔案作為 context
