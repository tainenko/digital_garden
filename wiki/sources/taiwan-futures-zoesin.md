# 台指期新手完整教學

原始來源：https://www.sinotrade.com.tw/richclub/futures/

---

## Key Takeaways

1. 台指期追蹤台灣加權股價指數，分大台（200元/點）、小台（50元/點）。
2. **結算日**：每月第三個星期三，結算價為 13:00~13:30 加權指數的簡單算術平均。
3. **保證金**：大台原始保證金約 184,000 元；維持保證金不得低於原始的 75%。
4. **盈虧範例**：台指期漲 1,909 點，大台獲利 381,800 元、小台獲利 95,450 元。
5. **新手注意**：不要只存原始保證金；關注法人籌碼；結算日前後波動大；避免凹單加倉。
