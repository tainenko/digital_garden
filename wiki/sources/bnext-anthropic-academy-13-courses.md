# Anthropic Academy 13 堂免費課程總覽（數位時代）

**Origin**：數位時代 bnext.com.tw，https://www.bnext.com.tw/article/90216/claude-13-free-lessons

## Key Takeaways

- Anthropic 推出 **13 堂全免費**線上課程，透過 Anthropic Academy 平台提供
- 課程分三大類：**開發技術實戰**（8堂）、**AI 素養**（2堂）、**教育應用**（3堂）
- 開發類課程大多有**結業證書**，Claude 101 和 Introduction to Agent Skills 無證書
- 最大課程：Building with the Claude API（84堂/8.1小時）、Claude with AWS Bedrock（85堂/8小時）、Claude with Vertex AI（85堂/8小時）
- 最快入門：AI Fluency: Framework & Foundations（14堂/1.1小時）、MCP 入門（16堂/1小時）
- 核心 4D 框架（Delegate / Describe / Discern / Diligent）貫穿所有素養類課程
- 需要有 Anthropic Academy 帳戶，帳戶免費，課程全免費
