## Key Takeaways

1. **Claude Code 是大腦，Higgsfield 是視覺手**：Claude Code 負責內容策略、文案撰寫、流程控制；Higgsfield MCP 負責圖像／影片生成，兩者透過 MCP 協定串連。

2. **MCP Server 安裝一行搞定**：在 Claude Code 的 `settings.json` 加入 `@higgsfield/mcp-server`（npx 啟動），設定 API Key 即可讓 Claude Code 直接呼叫 Higgsfield API。

3. **CLAUDE.md 是品牌一致性的關鍵**：在 CLAUDE.md 定義目標受眾、POV、語調、視覺風格、輪播格式，Claude Code 的所有輸出都會遵從這份規範。

4. **10 張輪播有固定結構**：封面（Hook）→ 現況共鳴（痛點）→ 問題放大 → 解決框架 → 結果預覽 → CTA（留言關鍵字），Claude Code 自動套用此結構。

5. **效率倍增**：傳統手工 2–5 小時／組；Claude Code + Higgsfield MCP 約 15–20 分鐘／組。一週內容可一次批量完成。

6. **此工作流服務 LIFE 系統的 I 層**：輪播作為 Influence 觸點，承接長根內容的拆解分發，並透過 CTA 留言漏斗串接 ManyChat → Skool。

7. **視覺規範要夠具體**：CLAUDE.md 的視覺風格描述越具體（如色號、字型、排版），Higgsfield 輸出的一致性越高；否則每次生成風格可能不同。

8. **人工審核仍必要**：AI 生成文案需確認是否符合第一手經驗與真實 POV（E-E-A-T 要求），不應完全自動發布。
