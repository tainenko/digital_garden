## Key Takeaways

- Claude 不只是聊天 AI，而是包含 Claude.ai、Claude Code、Cowork、Claude Code Channels 的完整工作系統
- **三大被低估功能**：Projects（記住背景）、Skills（永久套用工作流）、Cowork（接管電腦輸出成品）
- 2026 年 2 月後，Skills、Connectors、檔案建立全部對**免費版**開放
- Claude 可整合 Chrome、Gmail、Adobe（50+ 工具）、Figma、Slack 等所有主力工具
- Claude Dispatch 讓手機發指令、桌電在背景執行任務
- Anthropic Managed Agents 是雲端版自動化，不需拉 n8n 節點，目標驅動即可
- Claude Design（2026 年 4 月推出）讓非設計師用一句話生成 App 原型、簡報、Landing Page
- Figma MCP 開放 Beta，雙向讀寫，Claude Code 可一鍵產出符合 Design System 的前端代碼
- [[Skillsmap]] 是現成 Skills 市場，10,000+ 技能，一鍵安裝
